# 机器人实操语料的样本谱系与基准交付

多厂机器人实操语料的交付。数据以毫米、毫秒和设备原始帧号记录。 资料为本地合成样本。

## 源交付

`sources/` 存放 JSON 原件，文件名前两位是到达序号，同一序号内的各表属于同次交付。每个文件有 `intake`、`table`、`records`，记录 `id` 在所属表内唯一。`source-fields.json` 列出各表字段类型，空值用 `null`，空集合用 `[]`。业务时间按下方约定解释。

| 数据表 | 说明 |
| --- | --- |
| `segments` | 通道采集的真实覆盖及数据文件。 |
| `calibrations` | 控制器和相机的成对锚点。cam_ticks 和 ctl_ticks 各有两个。 |
| `labels` | 审校给出的动作区间以相机帧为单位。 |
| `links` | 同源凭证。 |
| `past_manifests` | 已发布作品的样本身份、动作和来源锚点。 |
| `exposures` | 实际接收回执；member 对应 past_manifests 记录。 |
| `scores` | 两次使用样本成绩。 |
| `coverage` | 盲测的最低覆盖与体量上限。 |

## 来源约定

`sources/` 下每份文件是一个提交包中的一张表，文件名前缀是接收序号。源内容按行登记，键作用域是表名和 id。各现场提供按通道分开的时间刻度。校准锚点之间是连续线性刻度；同一通道及拍次以明确被替代的校准为准，锚点外没有对应关系。格点上的片段边界按左闭右开处理。动作必须同时具有 cam 与 ctl 通道；通道可在文件边界连续拼接，导出的保留格式可自选，需携带原始采样值、定位和标注。帧资料和控制器资料各自的 ts 使用 segment 的设备刻度。
关联凭证表示同一物理演练的同源关系。只服从有编号的凭证，kind 为 repeat、mirror 或 replay。label 的 reviewed 表示已发布标签，pending 表示未复核；label_rule 是标签词表版，v1 与 v2 不能互换。修订的 applies 字段指向被替换的记录 id，空值代表新增。曝光回执的 role 为 train 或 blind；盲测成绩由每样本两方分别报送，score 为 0 至 100 的整数。调用方只接收同一批次的完整清单。盲测上限和覆盖下限按动作计数，scope 为场址与标签组合。

## 资料盘点

运行环境为 Python 3.11，盘点与资料校验仅使用标准库。盘点结果按到达批次显示表名及行数。

```sh
python source_inventory.py
python -m unittest discover -s tests -v
```

## 语料入湖与发布项目（`corpus/`）

在源交付之上提供完整的样本谱系、隔离与发布流水线，仅用标准库：

- 按 as-of 时点解析修订记录（`applies`），三时基（cam 帧、ctl 刻度、标注坐标）
  以校准锚点做精确分数换算，锚点外禁止外推；跨文件片段只在邻接处拼接，断点保留；
- 动作必须在 cam/ctl 两通道对同一物理区段可验证覆盖、标签已审、校准仍有效才交付，
  未审标签与无动作是不同状态；样本编号是内容身份，支持重建差异
  （失去对应 / 新增 / 边界微调 / 校准变更 / 词表变更）；
- 同源凭证按传递闭包形成隔离组，整组同进同出；历史训练/盲测曝光构成冻结约束，
  迟到凭证立即识别污染基准与各方见过的样本，之后按新关系隔离；
- 分包满足 `(场址, 标签)` 覆盖下限与盲测上限，不可行时交代短缺与卡住的来源组，
  禁止拆组；预览指纹在确认时复验，新证据使保证变化则旧候选不得发布；
- 新旧基准只在双方有效且同标签同校准的共同样本上逐样本比较，污染区段排除，
  不做整包分数比较；样本包携带原始采样值、定位、标注与完整谱系。

运行手册（含全部命令、退出码和本数据的预期结论）见 [`docs/runbook.md`](docs/runbook.md)。
隔离模式下从仓库根目录运行：

```sh
python -I -m unittest discover -t . -s tests -v
python -I corpus/cli.py --workdir out ingest
python -I corpus/cli.py --workdir out build --as-of 3
```
